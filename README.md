# Jarurat Care – Mini Healthcare Support Web App

## Project Overview

This project is a concept-level healthcare support web application created for the Jarurat Care internship assignment.

The application allows users to:

* Register as a volunteer
* Submit healthcare support requests
* Contact the NGO through a simple form
* Interact with an AI-powered healthcare support assistant

---

## Tech Stack

### Frontend

* React + Vite
* Tailwind CSS
* React Hook Form

### Backend

* Node.js + Express
* MongoDB Atlas (data storage)
* Groq LLM (primary) + OpenRouter (fallback)
* Pinecone + Xenova Embeddings (RAG system)
* Fuse.js (fuzzy search)

### Deployment

* Frontend: Vercel
* Backend: Render

---

## AI / Automation Idea

### AI FAQ Chat Assistant

The application includes an AI-powered chatbot that helps users by:

* Answering common healthcare-related questions
* Providing information about NGO services
* Guiding volunteers and patients to appropriate resources

### Workflow

User Question → Knowledge Base Search → AI Response

This reduces manual effort for NGO volunteers and provides instant support to users.

---

## NGO Use Case

Jarurat Care can use this platform to:

* Collect patient support requests
* Register and manage volunteers
* Answer common questions automatically
* Reduce response time for inquiries
* Improve accessibility of healthcare support information
